## 第1课：获取数据

**任务目标**：
- 使用 yfinance 获取多只股票的历史价格数据
- 支持用户自定义股票代码和开始日期
- 保存数据为 CSV 文件到 data/raw/ 目录

**实现方案**：

2. **主要功能**：
   - 用户交互式输入股票代码（支持多只股票，逗号分隔）
   - 用户自定义开始日期（结束日期自动设为当天）

3. **技术特点**：
   - 完全免费，无需 API 密钥
   - 支持美股、港股等多市场
   - 自动处理列名格式
   - 显示保存进度和行数

**核心代码结构**：

```python
class DataFetcher:
```

## 第2课：清洗数据

**任务目标**：
- 读取原始股票数据（CSV格式）
- 转换日期格式并排序
- 检查并处理缺失值
- 计算日收益率（pct_change）
- 保存清洗后的数据到 data/processed/ 目录

**实现方案**：
1. **数据加载**：
   - 自动定位 data/raw/ 目录下的所有 CSV 文件
   - 自动创建 data/processed/ 输出目录

2. **数据清洗流程**：
   - 转换 Close 列为数字类型（处理字符串问题）
   - 转换 Date 列为日期时间格式
   - 按日期排序
   - 检查缺失值并删除（dropna）
   - 计算日收益率（pct_change），填充第一行 NaN 为 0

3. **数据保存**：
   - 只保留需要的列（Date、Close、daily_return）
   - 保存为 CSV 文件到 data/processed/ 目录

4. **测试要点**：
   - 检查缺失值是否已处理
   - 检查收益率是否在合理范围内

**核心代码结构**：
```python
class DataCleaner:

    ├── clean_stock()       # 清洗单个股票数据
```

## 第3课：动量指标

**任务目标**：
- 计算三种动量指标（10天、20天、60天）
- 生成三种交易信号（20 vs 60、10 vs 60、三线多头）
- 统计买入/卖出/观望天数
- 保存信号数据到 data/signals/ 目录

**实现方案**：
1. **数据加载**：
   - 自动定位 data/processed/ 目录下的所有 CSV 文件
   - 自动创建 data/signals/ 输出目录

2. **动量指标计算**：
   - **动量10**：`Close / Close.shift(10) - 1`
   - **动量20**：`Close / Close.shift(20) - 1`
   - **动量60**：`Close / Close.shift(60) - 1`
   - 显示动量值范围（最小~最大）

3. **信号生成规则**：
   - **信号20 vs 60**：动量20 > 动量60 且动量20 > 5% → 买入(1)；动量20 < 动量60 且动量20 < -5% → 卖出(-1)
   - **信号10 vs 60**：动量10 > 动量60 且动量10 > 5% → 买入(1)；动量10 < 动量60 且动量10 < -5% → 卖出(-1)
   - **三线多头 (10_20_60)**：动量10 > 动量20 > 动量60 → 买入(1)；动量10 < 动量20 < 动量60 → 卖出(-1)

4. **结果统计**：
   - 统计每个信号的买入天数、卖出天数、观望天数
   - 验证信号值是否在合理范围内

5. **数据保存**：
   - 保存为 CSV 文件到 data/signals/ 目录
   - 包含原始数据 + 动量指标 + 三种信号列

**核心代码结构**：
```python
class MomentumIndicator:
    ├── __init__()              # 初始化目录和文件查找
    ├── load_data()             # 加载单个股票数据
    ├── cal_momentum()          # 计算动量10、20、60
    ├── signal_10_60()          # 信号：动量10 vs 动量60（加阈值5%）
    ├── signal_20_60()          # 信号：动量20 vs 动量60（加阈值5%）
    ├── signal_10_20_60()       # 信号：三线多头（10>20>60买入）
    ├── process_stock()         # 处理单个股票
    └── run()                   # 运行所有股票
```



## 第4课：Backtrader回测

**任务目标**：
- 使用 Backtrader 框架进行量化策略回测
- 同时回测三种动量信号（20/60、10/60、10/20/60）
- 设置初始资金、手续费、止损等参数
- 汇总所有回测结果并保存

**实现方案**：
1. **数据加载与合并**：
   - 从 data/raw/ 读取价格数据（OHLCV）
   - 从 data/signals/ 读取信号数据
   - 按日期合并，过滤时间范围（2020-01-01 至 2026-08-04）
   - 检查信号列是否存在

2. **自定义数据源类**：
   - 继承 `bt.feeds.PandasData`
   - 定义三条信号线（signal_20_60、signal_10_60、signal_10_20_60）
   - 映射 DataFrame 列名到 Backtrader 线名

3. **策略类设计**：
   - 同时监控三种信号，每个信号独立使用 10000 资金
   - **ATR控制仓位**：波动大少买，波动小多买
   - **止损机制**：亏损 20% 强制平仓
   - **手续费**：0.1%
   - **每笔风险**：使用可用资金的 30%

4. **回测运行**：
   - 循环所有股票和所有信号
   - 初始总资金 30000（3个信号 × 10000）
   - 添加 Returns 和 SharpeRatio 分析器
   - 提取总收益、夏普比率等指标

5. **结果汇总**：
   - 保存为 CSV 文件到 results/ 目录
   - 按信号类型分组统计平均收益和夏普比率
   - 统计盈利次数

**核心代码结构**：
```python
# 数据加载
load_and_merge_data(stock_code, project_dir)

# 自定义数据源
class PandasDataWithSignals(bt.feeds.PandasData):
    lines = ('signal_20_60', 'signal_10_60', 'signal_10_20_60')

# 策略类
class MultiSignalStrategy(bt.Strategy):
    ├── __init__()              # 初始化信号和记录变量
    ├── log()                   # 日志打印
    ├── notify_order()          # 订单状态回调
    ├── calculate_position_size() # 计算仓位大小
```
